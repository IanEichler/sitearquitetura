Links

Escolha o símbolo de cada link na lista. Se não encontrar o ideal, selecione "Outro (avançado)" e digite o nome de um ícone do lucide.dev/icons. Marque "Destaque" para deixar o botão em azul.
Para links externos, pode digitar só o endereço (ex.: youtube.com) — o "https://" é adicionado automaticamente. Para links internos do site, use /index.html#secao. Arraste pelo ícone para reordenar.

Pré-visualização — Página de Links

E-books

Escolha "Gratuito", "Pago" ou "Em breve". Para "Em breve" você pode deixar título, capa e link em branco. A capa pode ser enviada como imagem ou informada como caminho/link. O link de download pode ser um caminho de arquivo (ex.: /ebooks/meu-ebook.pdf — coloque o arquivo na pasta public/) ou um link completo (https://...). Para e-books gratuitos, também é possível enviar o PDF diretamente. O campo "Preço" só aparece nos e-books pagos. Evite arquivos muito grandes (acima de 1–2MB), pois eles são salvos junto com os outros dados.
